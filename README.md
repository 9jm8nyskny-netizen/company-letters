# منشئ الخطابات الرسمية

تطبيق ويب (ملف واحد `index.html`) لإنشاء خطابات الشركات بالترويسة الرسمية وتنزيلها PDF.

## المزايا
- ترويسات 6 شركات: لحظة كيف، ماما غزيل، شموخ الاستدامة، مؤسسة القحطاني، نقطة توازن للاستشارات الهندسية، حنيث الحجاز.
- قوالب جاهزة قابلة للتعديل: تعريف بالراتب، شهادة خبرة، إخلاء طرف، إنذار، مباشرة عمل، إجازة، نقل، قبول استقالة، تفويض، طلب سداد مخالفات مرورية، مرافق مساعد في الاختبار، اعتماد بدل مواصلات شهري، اعتماد إكرامية شهرية، طلب سلفة مالية، زيادة بدل السكن والمواصلات، إنذار كتابي بالفصل بسبب الغياب، تنبيه تجاوز العجز النقدي، طلب سداد مديونية وإقرار باستقطاع، إنذار أول بسبب كثرة المخالفات والعجز النقدي.
- خطاب رسمي عام، خطاب تحويل ترخيص إلى وطني 100%، تقرير تصفية.
- تقرير مخالفات موظف: ارفع ملف CSV المصدّر من AppSheet ويطلع التقرير (التاريخ والمخالفة والتفاصيل وملخص حسب النوع) بدون أي خصومات، مع فلترة بالفترة، والجدول الطويل يكمل في الصفحة التالية بنفس العناوين.
- الختم والتوقيع: إظهار/إخفاء، وسحب لتغيير المكان.
- سجل الخطابات وترقيم تلقائي لكل شركة.

## قاعدة البيانات (Firebase)
التطبيق مربوط بمشروع Firebase `company-letters` (Firestore في الدمام me-central2) مع تسجيل دخول بالبريد وكلمة المرور.
الحسابات تُضاف من Firebase Console ← Authentication ← Users (التسجيل الذاتي مقفل).
قواعد Firestore المقترحة في `firestore.rules`.
