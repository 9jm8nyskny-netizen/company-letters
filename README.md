# منشئ الخطابات الرسمية

تطبيق ويب (ملف واحد `index.html`) لإنشاء خطابات الشركات بالترويسة الرسمية وتنزيلها PDF.

## المزايا
- ترويسات 5 شركات: لحظة كيف، ماما غزيل، شموخ الاستدامة، مؤسسة القحطاني، حنيث الحجاز.
- قوالب جاهزة قابلة للتعديل: تعريف بالراتب، شهادة خبرة، إخلاء طرف، إنذار، مباشرة عمل، إجازة، نقل، قبول استقالة، تفويض.
- خطاب رسمي عام، خطاب تحويل ترخيص إلى وطني 100%، تقرير تصفية.
- الختم والتوقيع: إظهار/إخفاء، وسحب لتغيير المكان.
- سجل الخطابات وترقيم تلقائي لكل شركة.

## قاعدة البيانات (Firebase)
التطبيق مربوط بمشروع Firebase `company-letters` (Firestore في الدمام me-central2) مع تسجيل دخول بالبريد وكلمة المرور.
الحسابات تُضاف من Firebase Console ← Authentication ← Users (التسجيل الذاتي مقفل).
قواعد Firestore المقترحة في `firestore.rules`.
